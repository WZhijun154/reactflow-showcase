## Codebase Patterns
- **Framework:** Next.js 16 (App Router) with TypeScript, Tailwind CSS 4
- **Tailwind setup:** Uses `@tailwindcss/postcss` plugin (v4 style), import via `@import "tailwindcss"` in globals.css
- **Static export:** `output: "export"` in next.config.ts, images must be `unoptimized: true`
- **basePath:** `/reactflow-showcase` — all links and assets must account for this
- **Google Fonts:** Removed — incompatible with static export. Use system fonts.
- **React Flow:** `@xyflow/react` v12 — import from `@xyflow/react`, styles from `@xyflow/react/dist/style.css`
- **React Flow client component:** Pages using ReactFlow MUST have `"use client"` directive
- **Path alias:** `@/*` maps to `./src/*`
- **Tests:** `node:test` runner with `.test.mts` files in `tests/` directory, run via `npm test`
- **Typecheck:** `npx tsc --noEmit` or `npm run typecheck`
- **Build:** `npm run build` → static output in `out/`
- **Repo:** github.com/WZhijun154/reactflow-showcase
- **Branch:** feature/reactflow-showcase
- **Diagram pattern:** Each diagram has: data file in `src/data/`, custom node components in `src/components/diagrams/<name>/nodes/` with barrel `index.ts`, main diagram component using `DiagramWrapper`, wired into `DiagramContainer.tsx` switch
- **Node component pattern:** `"use client"`, import Handle/Position from @xyflow/react, interface for data, dark mode classes, hover effects (shadow + scale), handles for source/target
- **Data file pattern:** Export typed `Node[]` and `Edge[]` arrays, use smoothstep edge type, color-coded edges, animated for active paths
